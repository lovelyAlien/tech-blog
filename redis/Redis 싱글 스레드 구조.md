## Redis 싱글 스레드 구조
![[image-2.png]]

Redis는 **싱글 스레드 이벤트 루프 구조로 동작하며, I/O Multiplexing을 통해 많은 요청을 하나의 스레드에서 효율적으로 처리합니다.**

Redis는 기본적으로 싱글 스레드 이벤트 루프 구조로 동작합니다.

클라이언트 요청은 Redis 서버로 들어오면 이벤트 큐에 저장되고,
Redis는 하나의 스레드가 순차적으로 명령을 처리합니다.

대신 Redis는 epoll 기반 I/O Multiplexing을 사용해서 여러 클라이언트 연결을 동시에 관리합니다.
그래서 하나의 스레드에서도 수많은 연결을 효율적으로 처리할 수 있습니다.

싱글 스레드를 사용하는 이유는 **락 경쟁이나 컨텍스트 스위칭을 제거하여 성능을 높이기 위해서입니다.**
