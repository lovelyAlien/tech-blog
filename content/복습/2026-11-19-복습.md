## 요약

### MSA는 대규모 트래픽 때문에 쓰는 게 아니다

> 트래픽은 MSA를 쓰는 이유 중 하나일 뿐이다. 핵심은 **독립 배포, 팀 자율성, 부분 확장, 장애 격리**다.

- 이유: 독립 배포, 팀 분리, 부분 확장, 장애 격리, 기술 다양성
- 모놀리식도 수평 확장으로 상당한 트래픽을 감당한다. 트래픽과 관련된 건 "부분 확장"뿐이다.
- 비용: 서비스 간 호출 실패, 분산 트랜잭션·정합성(이벤트, Saga), 로컬 개발·배포·로그 추적 복잡도
- 팀이 작고 독립 배포 요구가 없으면 이점은 거의 없고 비용만 남는다.
- 포트폴리오에서는 직접 겪은 비용과 판단 기준을 말한다. "모듈러 모놀리스로 시작, 경계가 검증되면 분리."

**헷갈렸던 것**
| 처음 이해 | 정확한 이해 |
|---|---|
| MSA는 트래픽이 많아서 쓴다 | 트래픽은 "부분 확장" 하나뿐. 독립 배포·팀 분리·장애 격리가 핵심 |
| 사이드 프로젝트의 MSA는 경험으로만 어필 | 학습 목적을 밝히고 직접 겪은 비용과 판단 기준을 말하면 설득력이 있다 |

### 바운디드 컨텍스트와 애그리거트는 무엇이 다른가

> 바운디드 컨텍스트는 **의미가 통하는 큰 경계**, 애그리거트는 그 안에서 **일관성을 지키는 작은 묶음**이다. 애그리거트 루트는 그 묶음의 유일한 진입점이다.

- 컨텍스트 = 의미(용어)의 경계, 애그리거트 = 트랜잭션·일관성의 경계. 컨텍스트 ⊃ 애그리거트
- 애그리거트 안은 강한 일관성(한 트랜잭션), 애그리거트 간은 ID 참조 + 도메인 이벤트로 최종 일관성
- 컨텍스트 경계 너머는 API·이벤트로 통신하고, 한 트랜잭션에서는 가급적 애그리거트 하나만 수정한다.
- 루트 vs 파사드: 루트는 불변식 보호(우회 불가, 규칙 보유), 파사드는 편의(우회 가능, 위임만)
- 컨텍스트는 논리적 경계, 마이크로서비스는 배포 단위. 컨텍스트 하나를 서비스 하나로 나누는 게 일반적 출발점이지만 모놀리스 안에서도 컨텍스트는 나눌 수 있다.

**헷갈렸던 것**
| 처음 이해 | 정확한 이해 |
|---|---|
| 컨텍스트와 애그리거트는 둘 다 경계라 비슷하다 | 무엇의 경계인지가 다르다: 의미 vs 일관성(트랜잭션) |
| 루트와 파사드는 둘 다 단일 창구라 같다 | 창구를 두는 이유가 다르다: 불변식 보호 vs 사용 편의 |
| 바운디드 컨텍스트 = 마이크로서비스 | 컨텍스트는 논리적 경계, 서비스는 배포 단위 |

**그림으로 보기**
컨텍스트(의미 경계) 안에 애그리거트(일관성 경계)가 여러 개 들어 있는 포함 관계를 보기

```
쇼핑몰 시스템
├─ [주문 컨텍스트]  ← 의미의 경계
│    ├─ (Order 애그리거트: Order + OrderLine)  ← 일관성의 경계
│    └─ (Cart 애그리거트: Cart + CartItem)
├─ [결제 컨텍스트]
│    └─ (Payment 애그리거트)
└─ [배송 컨텍스트]
     └─ (Delivery 애그리거트)
```

### 애그리거트는 무엇으로 구성되고 엔티티는 어디에 속하나

> 애그리거트는 불변식을 함께 지켜야 하는 객체들의 묶음이고, 루트 엔티티·내부 엔티티·값 객체로 구성된다. 내부 엔티티는 하나의 애그리거트에만 속하며, 다른 애그리거트와는 ID 참조나 값 복사로만 연결한다.

- 애그리거트 = 묶음 + 진입점(루트) + 단위(저장·트랜잭션)
- 엔티티는 ID로 구분되고 상태가 바뀐다. 값 객체는 값이 같으면 같은 것이고 불변이다.
- 내부 엔티티는 한 루트만 소유한다. 주인이 둘이면 불변식 책임과 트랜잭션 경계가 흐려진다.
- 다른 애그리거트 정보는 ID 참조(최신 원본) 또는 값 복사(당시 값 보존)로 쓰고, 객체 직접 참조는 지양한다.
- 애그리거트는 작게 잡고, 리포지토리는 루트 단위로만 둔다.

**헷갈렸던 것**
| 처음 이해 | 정확한 이해 |
|---|---|
| 같은 엔티티를 여러 애그리거트가 공유할 수 있다 | 한 루트만 소유. 다른 곳은 ID 참조나 값 복사 |
| 구성 요소마다 정식 이름이 있다 | 정식 이름은 루트뿐, 나머지는 엔티티·값 객체로 부른다 |
| 애그리거트는 크게 잡아야 안전하다 | 클수록 락·충돌 범위가 커지므로 작게 잡는다 |

**그림으로 보기**
Order 애그리거트가 Product를 객체가 아니라 ID와 값 복사로 연결하는 모양을 보기

```
Order 애그리거트              Product 애그리거트
 ├─ OrderLine                 └─ Product (루트)
 │    ├─ productId ──ID 참조──────▶
 │    └─ 주문 당시 상품명·가격 (값 객체 복사)
```
