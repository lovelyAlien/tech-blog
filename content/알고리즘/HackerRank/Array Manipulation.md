# Array Manipulation: 차분 배열 + 누적합으로 구간 업데이트를 O(1)에

구간 업데이트가 많고 조회는 마지막에 한 번만 하는 문제는 차분 배열로 푼다.

- 문제: [HackerRank - Array Manipulation](https://www.hackerrank.com/challenges/crush/problem)

## 문제 요약

크기 n인 0 배열에 "a~b 구간에 k를 더하라"는 연산을 m번 한 뒤 최댓값을 반환한다.
(n ≤ 10⁷, m ≤ 2×10⁵, k ≤ 10⁹)

```
n = 5, queries = [[1,2,100], [2,5,100], [3,4,100]]
[100, 100,   0,   0,   0]
[100, 200, 100, 100, 100]
[100, 200, 200, 200, 100]  →  200
```

## 접근: 구간 전체 대신 경계 두 곳만 표시

매번 구간을 직접 돌면 O(n·m) = 최대 2×10¹²이라 시간 초과가 난다.

구간 [a, b]에 k를 더해도 값이 **바뀌는 곳은 두 군데뿐**이다.

```
예: 길이 7, [3, 5]에 +4

값
 4 |          ┌───────────┐
   |          │           │
 0 |──────────┘           └──────────
     1    2    3    4    5    6    7
               ▲               ▲
            경계 ①           경계 ②
          (a) +4 올라감   (b+1) -4 내려감

위치:       1    2    3    4    5    6    7
arr:        0    0   +4    0    0   -4    0   ← 앞 칸 대비 변화량
```

- `arr[a] += k`: 여기서부터 k만큼 올라간다
- `arr[b+1] -= k`: 여기서부터 다시 내려간다 (b까지는 유지해야 하니 **b+1**)
- 구간 안쪽은 앞 칸과 차이가 없으니 건드리지 않는다

모든 쿼리를 표시한 뒤 **누적합을 한 번** 돌리면 실제 값이 복원된다.

## 처음 작성한 코드 (오답)

```java
// "지금까지 겹친 구간" 하나만 들고 다니며 좁혀 가는 방식
int answer = k;
for (...) {
    if (nextB < a || nextA > b) {
        answer = Math.max(k, nextK);        // 새 구간을 추적하지 않음
    } else {
        a = Math.max(a, nextA);             // 교집합으로 좁힘
        b = Math.min(b, nextB);
        k = k + nextK;
        answer = Math.max(answer, k);
    }
}
```

**반례:** `[1,3,1], [1,1,1], [3,3,5]`의 정답은 6(3번 위치 = 1+5)인데 5를 반환한다.
[1,1]로 좁히는 순간 "3번 위치에 +1이 남아 있다"는 정보가 사라진다.
→ 값이 쌓이는 위치는 여러 곳일 수 있어서, **교집합 하나를 좁혀 가는 방식은 성립하지 않는다.**

## 수정한 풀이

```java
public static long arrayManipulation(int n, List<List<Integer>> queries) {
    long[] arr = new long[n + 2];
    for (List<Integer> q : queries) {
        arr[q.get(0)] += q.get(2);       // 경계 ①
        arr[q.get(1) + 1] -= q.get(2);   // 경계 ②
    }

    long sum = 0, max = 0;
    for (int i = 1; i <= n; i++) {
        sum += arr[i];                   // sum = i번 위치의 실제 값
        max = Math.max(max, sum);
    }
    return max;
}
```

**시간 O(n + m), 공간 O(n)**

## 주의할 점

- **`int` 오버플로**: 합은 최대 10⁹ × 2×10⁵ = 2×10¹⁴까지 간다. `long`을 써야 한다.
- **배열 크기 `n + 2`**: 1-indexed이고, `b = n`이면 `arr[n+1]`에 접근한다.
- **`n`을 안 쓰는 풀이는 의심하기**: 위치별 값을 다뤄야 하는 문제다.

## 한 줄 정리
> 구간 업데이트가 많고 조회가 마지막에 한 번이면 **시작점에 +k, 끝 다음 칸에 -k**만 표시하고 누적합으로 복원한다.
