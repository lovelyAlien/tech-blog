## 웹 크롤러
- 웹에 새로 올라오거나 갱신된 컨텐츠를 찾아냄
- 검색 엔진에 널리 쓰이는 기술
- 로봇 또는 스파이더라고도 부름

## 웹 크롤링
- 웹은 **그래프 구조**
    - 웹 페이지 = 노드(Node)
    - 하이퍼링크 = 간선(Edge)
- 따라서 크롤링은 **그래프 탐색 문제**
- 대부분의 크롤러는 **BFS(너비 우선 탐색)** 기반으로 동작

### 미수집 저장소
- 웹 크롤러는 다운로드 할 URL, 다운로드된 URL로 나눠서 관리
- 다운로드할 URL 관리 컴포넌트 = 미수집 URL 저장소 = FIFO 큐

> 왜 미수집 저장소는 FIFO 큐?

- 아직 다운로드하지 않은 작업 목록
- 작업 대기열(Job Queue)
- 웹 크롤링의 기본 알고리즘은 BFS 기반

### HTML 다운로더
- 사람 대신 자동으로 브라우저 역할하는 프로그램
- HTTP 통신으로 HTML 가져옴

### 컨텐츠 파서
- 다운로더가 가져오는 건 문자열일 뿐
- HTML은 계층구조이다. 파서는 이것을 DOM 트리로 변환
