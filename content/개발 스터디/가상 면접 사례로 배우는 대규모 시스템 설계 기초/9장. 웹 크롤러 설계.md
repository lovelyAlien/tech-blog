## 웹 크롤러 아키텍처
![[9장. 웹 크롤러 설계-20260222-174713.png]]

HTML 다운로더
- 사람 대신 자동으로 브라우저 역할하는 프로그램
- HTTP 통신으로 HTML 가져옴

컨텐츠 파서
- 다운로더가 가져오는 건 문자열일 뿐
- HTML은 계층구조이다. 파서는 이것을 DOM 트리로 변환






웹은 본질적으로 **그래프(Graph)** 구조야.
- 웹 페이지 = 노드(Node)
- 하이퍼링크 = 간선(Edge)
즉, 크롤링은 결국 **그래프 탐색 문제**야.









웹 크롤러는 일반적으로 **BFS 기반**으로 동작
- 깊게 한 사이트만 파지 않음
- 전체 웹을 균형 있게 탐색
- 검색엔진에 적합





실전에서는 이것보다 복잡해서 나온게 우선순위 기반 크롤링

- Queue 대신 Priority Queue 사용
