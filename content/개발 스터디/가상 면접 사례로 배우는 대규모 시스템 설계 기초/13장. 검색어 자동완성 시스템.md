## 트라이 자료구조
문자열들을 간략하게 저장할 수 있는 자료구조
- 트리 형
- 루트 노드 빈 문자열
- 각 노드는 글자 하나 저장, 26개의 자식 노드 가질 수 있다.
- 각 트리 노드는 하나의 단어 또는 prefix string

### 트라이 데이터베이스
트라이 데이터베이스는 지속성 저장소다. 선택지는 두 가지
- 문서 저장소:
	- 주기적으로 트라이를 직렬화하여 DB에 저장
	- ex. MongoDB
- 키-값 저장소
	- 접두어를 키로 변환
	- 각 노드에 보관된 모든 데이터(우선 순위 등)를 값으로 변환
