## 그 외 개발 스터디 서적 후보군

- 아파치 카프카 애플리케이션 프로그래밍 with 자바
	- Kafka의 **역할과 철학** (왜 DB 트랜잭션으로 안 되는가)
	- Producer / Consumer 구조
	- 파티션, 오프셋, 컨슈머 그룹 개념
	- **메시지 유실·중복·순서** 문제를 어떻게 다루는지
- HTTP 완벽 가이드
	- HTTP 요청/응답 구조
	- Keep-Alive, 캐시, 쿠키, 프록시    
	- 인증, 상태 관리, 연결 관리 
- 이펙티브 자바
	- 객체 생성과 소멸
	- 불변 객체, equals/hashCode
	- Optional, Enum, Builder 패턴
- JPA 프로그래밍
	- ORM을 정확히 쓰는 방법
- 자바 웹 프로그래밍 Next Step
	- Spring 이전에 웹을 이해
	- HTTP 요청이 서버 내부에서 처리되는 과정
	- 프레임워크가 해결해주는 문제들
- 모던 인 자바 액션
	- 람다, 함수형, 리엑티브 프로그래밍
- 리얼 MySQL
	- DB 성능과 내부 동작
	- 인덱스 구조
	- 실행 계획
	- 락, 트랜잭션, MVCC
	- 성능 튜닝 기초
- gRPC 시작에서 운영까지
- MongDB 완벽 가이드
