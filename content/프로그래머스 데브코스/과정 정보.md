## 커리큘럼

### 학습 영역

1. 도메인 설계 & 대용량 처리: DDD, 결제·정산 도메인, Spring Batch
2. MSA & CI/CD 자동화: Kafka, Kubernetes, CI/CD, 모니터링
3. 주문·결제 플랫폼 구현: Elasticsearch 검색, PG 결제, 무중단 배포
4. Spring AI & RAG: LLM 호출, WebFlux 스트리밍, RAG
5. 개인 맞춤 추천 플랫폼: Vector DB, RAG, Kubernetes 배포·운영

### 단계별 구성

- [ ] **STEP 01 – DDD**: 상품·장바구니·결제 도메인, PG 연동, 결제 상태 트랜잭션, 데이터 보안
- [ ] **STEP 02 – 정산·대용량**: 정산 도메인·수수료 로직, Spring Batch 대량 처리, 정산 로그·오류 처리
- [ ] **STEP 03 – MSA·비동기 메시징**: Spring Event로 도메인 분리, Kafka 기반 회원·인증 분리, API Gateway, 서비스 디스커버리
- [ ] **STEP 04 – Kubernetes CI/CD**: GitHub Actions 배포 자동화, K8s 무중단 배포, Prometheus·Grafana 모니터링·로깅
- [ ] **STEP 05 – 검색 마이크로서비스**: Elasticsearch 상품 검색, 동의어, 자동완성, 키워드 랭킹, 색인·성능 튜닝
- [ ] **FINAL**: 최종 발표·회고, 면접 및 이력서·포트폴리오 컨설팅

### 프로젝트

- [ ] **PROJECT 1 – 주문·결제 플랫폼**: MSA 설계, K8s 무중단 배포, PG 결제 연동, 대규모 트랜잭션 관리
- [ ] **PROJECT 2 – AI 기반 개인 맞춤 추천 플랫폼**: Spring AI, RAG, Vector DB, AI 추천 시스템
